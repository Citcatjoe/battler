Rendu de référence de battler-ui-kit.css. Toute implémentation doit être visuellement identique à cette page (hauteurs, coupes, icônes, états).

Deux familles d'icônes — ne jamais les mélanger

Glyphes de commande — SVG au trait, une couleur (currentColor), grille 24, trait 1,75. Pour tout ce qui se clique : boutons, onglets, barre de lecture, liens. Liste ci-dessous, aucune autre source.
Emblèmes de contenu — images peintes en couleur. Réservés à ce qui appartient au jeu : compétences, statuts, reliques, objets, portraits. Jamais dans un bouton de commande ; un bouton « Combattre » ne doit pas ressembler à une compétence.
